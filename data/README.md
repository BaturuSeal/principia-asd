# Compact scenario edition

40 prepared, grouped, retrospective example scenarios from 100 audited historical cases. Each package is under 10 MB expanded, including protected outputs. Publication remains gated on final rights review. Runtime uses only bundled compact tables. Test targets stay outside this directory.

See the [example scenario guide](SCENARIO_GUIDE.md) for readable introductions, task definitions and variable meanings.

The software acceptance handoff does not change this frozen edition or approve scientific admission. See the companion project's `ACCEPTANCE.md` and `docs/RESEARCH_BACKLOG.md`.
