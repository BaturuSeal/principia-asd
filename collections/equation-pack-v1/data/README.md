# Connected-equation scenarios

Three compact, source-aligned local research scenarios for thermal radiation, viscous flow and coupled viscoelastic response. Use with Principia-ASD rc5. These extend the local library; the frozen forty-scenario edition remains unchanged.

Each scenario documents native units, group splits, exclusions, source hashes and scientific limits. The equation templates are disclosed physical priors, never novelty claims. Private targets remain in a separate evaluator directory. Run `python prepare.py --help` for exact reconstruction; install the matching package first.
