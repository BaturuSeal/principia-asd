# Forest-soil respiration across sites

Compare thermal activation, water limitation and root-exclusion associations using soil measurements from complete held-out sites. The task retains site heterogeneity and does not identify causal effects of management.

## Scientific contract

Whole site families. Dev Llobera/Secanella/St Christol; test Gamiz/Kacergine/Kranzberg-Freising/Saint Mitre/RincondelBatovi; remaining eligible sites train. Adjacent Karstula and Dumbravita families never cross partitions.

- Q10 is a finite-range ecosystem response, not a universal activation law
- Site-held-out transfer with unmodelled soil, management and instrument differences
- Source flux is an author-derived chamber measurement; concentration-fit slope and intercept are prohibited predictors
- Water content is not pore saturation; oxygen access is an unmeasured hypothesis
