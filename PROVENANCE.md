# Provenance and reuse

This is a standalone package with a new local UI and task-contract runtime. Small canonical-hashing and record utilities originated in the local Principia preview; provider accounting, numerical execution, method control flow and evaluation were reviewed and substantially rewritten on 11 October 2026. No application runtime, virtual environment, credential store or prior campaign outputs are bundled.

The compact data derive from the existing Principia-100 registry and native prepared measurements. `scripts/curate_v2.py` joins canonical scenario identities and checks opaque reference sample IDs, allowed inputs and groups. The graph-certificate case is never inferred from the stale numeric GEO folder. All 100 cases remain in the admission audit; 40 satisfy the current numeric package gate. Source terms and calibration/timing limits remain applicable. This is a prepared-measurement track, not a raw multimodal track.

Each new worker uses a content-addressed source snapshot in the private workspace. Campaign manifests pin driver code, runtime hashes, data edition, exact role mappings, capability receipts and price snapshot. These copies are source only; environments are never copied into the public roots.

External algorithm names are reserved for verified adaptations. The [AgentRxiv](docs/method-cards/agentrxiv.md), [Agent Laboratory](docs/method-cards/agent-laboratory.md) [data-to-paper](docs/method-cards/data-to-paper.md) and [Asta AutoDiscovery](docs/method-cards/asta-autodiscovery.md) adaptations record pinned upstream revisions, retained algorithms, restricted execution boundaries and upstream license/NOTICE snapshots (MIT or Apache-2.0). Other pending registry entries cite upstream sources but are not shipped as faithful implementations. No upstream license obligations are treated as satisfied merely because a method name appears in the registry. The old preview is retained privately for audit and excluded from current ranking.

AgentRxiv is an independent private-archive coordinator based on the pinned paper revision `arXiv:2503.18102v1`. It reuses our attributed Agent Laboratory adaptation. No paper text or upstream preprint-server implementation is bundled. Its lexical retrieval, sequential two-lab schedule and expanded numerical formula reuse are disclosed departures.
