## P100-006: source-grid coordinates and ion readout

The four bound local assets are the NIST source record, its README, the `FIG3b` ion-readout CSV and the excluded `FIG4b` fit-summary CSV. Their identities and hashes come from the existing scenario registry. The source record is version **1.0.3**, while the README says **1.0.0**; both are preserved rather than silently reconciled. No source data was downloaded again.

The selected file has **300,000 rows**: 1,000 detuning coordinates crossed with 300 probe-Rabi coordinates. All coordinates are unique in the complete rectangular grid, ordered first by detuning, then by increasing Rabi frequency. Detuning spans -999.4443398 to 499.3758546 MHz; probe frequency spans 0.512376327 to 7.565145804 MHz. Its header explicitly identifies ion amplitude. The README's final format line incorrectly says EIT amplitude for the ion spectra; the filename, title, component description and CSV header identify the selected channel. We do not mix in the optical response.

The stored coordinates are **delta_c/(2*pi)** and **Omega_p/(2*pi)** in MHz. The reader applies no additional factor of 2*pi, normalization, response fitting or calibration. The historical absolute-detuning limit of 60 MHz selects **80 detuning coordinates and 24,000 rows**. There are no nonfinite responses in this snapshot; zero/negative responses would be preserved rather than treated as invalid. The other **276,000 rows** remain accounted for as outside the task's fixed domain, not discarded for unfavorable performance.

Ten contiguous blocks each contain 30 source-grid Rabi coordinates. Blocks 06 and 09 remain test; 05 and 08 remain dev; the other six remain train. The resulting **14,400 / 4,800 / 4,800 rows** and every sample/group identity match the historical tables, with zero numerical differences. All detuning samples for a given coordinate stay in one partition. Separation of coordinate blocks does not establish independent cells, acquisitions or devices.

The dense grid's relationship to original instrument scans remains unresolved. The separate fitted-summary file contains **15 probe settings**, whereas the spectral export contains 300 distinct probe coordinates. This discrepancy is a provenance question, **not proof of interpolation**. The [source paper](https://arxiv.org/html/2509.15463v1) describes the one-cell measurement setup, color-map spectra and fitted widths/amplitudes, but the inspected methods do not document the dense export's interpolation or resampling procedure. The [NIST record](https://data.nist.gov/od/id/mds2-3951) and local README also do not resolve that processing chain. Do not count 300 exported coordinates as 300 independent experimental repetitions.

Fitted linewidths and amplitudes, optical spectra, RF calibration fits, noise and sensitivity summaries are excluded from every predictor. The fit-summary file is bound only as audit context and is not parsed by the task reader. Source row and Rabi-coordinate index preserve exact lineage; the index is not an experimental identity. This task remains **pending source-processing and scientific review**, even after exact reconstruction.

## P100-049: measured relaxation and causal calibration

The registered Basytec GITT source contains **315,306 native records in 957 consecutive-command segments**. Headers specify hours, volts and amperes, identify cell **Hydra.0b_A**, and distinguish the 2022 experiment from the later file-conversion timestamp. Relative acquisition time is used without inventing a timezone. All selected numeric fields are finite; timestamps and DataSet IDs strictly increase.

The reader merges consecutive equal commands across changes of the source `Line` step number. A rest can contain **four step numbers** without becoming four independent samples or groups. It retains **476 Pause segments** after complete Charge/Discharge commands that last at least 1,800 seconds. Every retained rest has exactly zero measured current. Two other rest segments remain explicit exclusions. The preceding current can vary and briefly cross zero; the current feature is specifically its **last measured sample**, not an ideal constant-current, mean-current or integrated-charge assertion.

All **1,904 eligible targets** have a native sample within the declared 15-second tolerance at 300, 600, 1,200 and 1,800 seconds. The largest actual timing error is approximately **0.001047 seconds**. Prefix features use only the last actual samples at or before 10, 60 and 120 seconds. The final prefix sample ranges from **110.000012 to 118.893808 seconds**; a value labelled `u120` is not falsely described as measured at exactly 120 seconds. Source-row references and actual `t60`/`t120` are retained.

The historical **1,216 train / 304 dev / 384 test-input rows**, in **304 / 76 / 96 whole rest blocks**, remain unchanged. Development acquisition ends at 475.731876 hours; test starts at 475.773639 hours. Train and dev ranges interleave. Thus the test boundary is chronological, but the compact development allocation is not the original legacy forward-fold policy and must not be called prospective train-to-dev validation. The compact contract already declares whole-group allocation, so this review preserves it and records the chronology limits without inventing a new temporal guarantee.

Native decimal parsing matches historical public values within the existing 1e-12 tolerance. The largest difference is **6.30e-17**, caused by decimal parsing of the current feature; numerical parity is not described as bitwise equality with the old tables. Replay of the new reader's own generated artifacts is checked separately for byte identity. No numerical values in the frozen edition are changed.

Only the GITT run supplies measurements. The later January 2023 POCV file, charge/state/cycle counters and future rest voltages cannot enter its prefix inputs. All four registered files, including source metadata, remain hash-bound. The metadata catalog is version **0.5.0** and contains placeholder creator entries for this dataset. Those entries must not be republished as verified authorship; attribution must be reconciled with the acquisition provider and repository record. The inherited CC BY 4.0 statement alone does not close notice packaging.

The task is within-cell, prefix-conditioned retrospective voltage prediction. Neighboring blocks share cell history and degradation state. It cannot demonstrate independent-cell transfer, diffusion identification or causal battery mechanisms on accuracy alone. Cell-level replication, suitable perturbation standards, accurate attribution, rights packaging and scientific contract approval remain open.
