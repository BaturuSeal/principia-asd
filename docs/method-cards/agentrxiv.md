# AgentRxiv — Principia adaptation

`agentrxiv-adaptation-v1` implements two laboratories that publish completed reports into a private archive, followed by an executed experiment using a peer laboratory's formula. The source is Schmidgall and Moor's [AgentRxiv paper, arXiv:2503.18102v1](https://arxiv.org/abs/2503.18102v1). The inspected paper snapshot and source scope are recorded in [the source receipt](../source-reviews/agentrxiv-2503.18102v1.json).

This independently written coordinator reuses our [Agent Laboratory v2 adaptation](agent-laboratory.md), with upstream revision `d9017d90e329112d2a80b7712f37ee9094d2cd27` and its packaged MIT notice. No paper text, upstream preprint server or external implementation is vendored. Our implementation is MIT licensed; naming the paper does not claim reproduction of its results.

## Executed mechanism

1. Lab A and Lab B each run a research, planning, engineering, experimental critique, program revision and reporting cycle. GLM plans, DeepSeek writes and revises expressions, Qwen critiques actual computations, and Kimi reports both experiments with verified cohort counts. Each lab has separate candidate and failure state. Initial calls cannot see the peer's report or results. Both use the same allowed measurements and model roles; their differing research emphases do not establish independent evidence.
2. Only a cycle passing all laboratory conformance checks can publish a completed report. The archive starts empty for every attempt and retains report content hashes, laboratory identity, computed experiments and source evidence hashes. Publication is persisted as an event and in the final submission. Incomplete work remains in the attempt record outside this archive.
3. Lab A generates an archive query using its own completed report. The host retrieves a completed foreign report using cosine similarity between lexical token counts, with deterministic ties. This replaces the paper's embedding retrieval. With two initial labs there is only one eligible peer report; the pilot cannot establish retrieval quality.
4. GLM selects an exact successful experiment from the retrieved report. DeepSeek proposes an additive or multiplicative extension. The host expands the donor's complete expression into the new program. A report citation alone cannot satisfy reuse. Every donor coefficient remains explicit and is refitted on train, with its recorded value used only as initialization; extension parameters cannot collide. All operations count toward complexity.
5. Qwen critiques the executed follow-up; DeepSeek revises its extension; Kimi reports both follow-up experiments and the exact peer report. Completion requires two locally checked follow-up structures, a structural revision, at least one valid peer-derived experiment and correct experiment/report/cohort references. A completed follow-up becomes a third archive publication.

The bounded configuration has **18 model requests and at most six expression-program checks**: two initial six-request laboratory cycles and one six-request archive cycle. All laboratories share the outer 32-call, 40-minute, 1,000-fit, 8,000-structure, eight-parameter, 4 GiB and monetary limits. Fit counts, optimizer evaluations, failures and CPU/wall accounting remain explicit. Labs execute sequentially within one worker; at most four scenario workers run concurrently.

## Adaptation boundary and retained evidence

This is fixed-contract, CPU numerical rule discovery. It does not reproduce unrestricted program generation, live literature acquisition, a public archive, asynchronous laboratory networks or the paper's empirical workload. It uses one peer transfer, not an unbounded sequence of accumulating research. Archives never carry across scenarios or attempts. Test feedback cannot enter the archive or the same inquiry.

`submission.json:method_evidence` contains initial laboratory lifecycles, report publications, retrieval queries and hashes, the actual reused expression, parameter policy, both follow-up computations, all handoffs, source lineage and conformance. The UI displays these separately from unreviewed model prose. The final rule portfolio uses the common development-selection policy; private-test assessment occurs only after the full cohort submission freeze, without model calls.

Missing execution or invalid references produce `incomplete_method_execution` with no ranked rules. Provider/transport failures remain failed attempts and unresolved charges stay reserved. Failed experiments and incomplete donor reports are retained. Synthetic tests verify isolated lab state, shared budgets, publication/retrieval/execution order, actual expanded reuse, rejection of colliding parameters or fabricated references, hash mutation detection and empty archives on new tasks.

Executed reuse establishes a computational dependency. It does not prove that the extension improves prediction, that a donor idea is novel, that the formula is causal, or that reports corroborate each other independently. Scientific review remains `not_assessed`. The [engineering pilot preregistration](../AGENTRXIV_PILOT_V1.json) fixes all eight assignments before paid execution; its outcomes remain separate from the primary ranking.

The completed pilot retained six complete and two incomplete attempts, with 18 valid rule assessments. All 144 recorded responses and eight assessments replayed exactly offline. Incorrect report binding and exhausted parameter capacity remain visible failure boundaries. See the [pilot review](../AGENTRXIV_PILOT_REVIEW.md); no comparison-ready or scientific-benefit claim follows from this engineering result.
