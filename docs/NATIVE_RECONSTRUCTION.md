## Run a recipe

Use a new destination outside the three upload roots and the source directory:

```bash
principia-asd prepare \
  --native-recipe configs/preparation/P100-012.raw-v1.json \
  --source-root /path/to/local-datas/_benchmark_100/release_candidate \
  --output-root /path/to/private-workspace/new-draft/P100-012 \
  --compare-scenario /path/to/ASD-Scenarios-26Oct10/scenarios/P100-012
```

For another supported scenario, use its corresponding recipe and scenario. `--compare-scenario` is optional, but when supplied its exact historical contract hash must match. It checks every development value and permitted test input by sample ID and group, with fixed `1e-12` absolute/relative tolerances. New receipts also report whether each split's sample membership is unchanged. This does not read protected test targets or use test performance to select a correction.

Existing destinations are never overwritten. The result is marked `draft_not_admitted`; it cannot silently replace the active edition or completed comparisons. The existing `prepare --settings ... --spec ...` grouped-CSV import remains available.

Each draft contains compact public tables, a source recipe, native row/line and calibration lineage, the exact preparation environment, an executable `preprocessing/prepare.py` and a reconstruction receipt. The script rebuilds into another new directory and rejects a different reader, split utility, record utility or NumPy version. Stable identities and deterministic gzip encoding support byte-identical replay. Hash-bound input checks fail on missing, changed or path-escaping source files.

The XRR reader expands the wavevector transformation and calibration means explicitly. It rejects unexpected axes/units/wavelength, correction factors, nonmonotone coordinates and row layouts that would break source-line lineage. Wafer identities come from the registered file manifest and deposition mapping, not a guessed scenario folder number.

The XLSX reader reads stored cells directly with a bounded standard-library ZIP/XML parser. It is intentionally limited to these measured columns and known units; formulas, unresolved worksheet relationships, unsafe paths, duplicate members, excessive expansion and invalid clocks are errors. It does not recalculate a workbook or accept cached formula results as native measurements. Non-numeric source rows are recorded, not silently forgotten.

The JSONL reader rejects duplicated fields/checkpoints, ambiguous stage flags and inconsistent architecture identities. It uses only hot-run validation measurements and explicit architecture metadata. Neither final-loss summaries, cooldown outcomes, fitted states nor checkpoints beyond the forecast horizon become inputs. Missing source checkpoints remain documented missing observations. The 4,194,304-token step conversion is corroborated by the registered extraction source. Shared training and validation datasets mean architecture separation does not establish independent scientific experiments.

The FET reader rejects unexpected columns, formulas, nonfinite currents, duplicate/reversed voltages and missing calibration anchors. All three calibration rows are excluded from scored responses. This is offline calibrated reconstruction: the +20 V endpoint is available by contract and is not a causal sweep forecast. Source headers are anonymous `wave` labels. V/A units and the association of columns with devices are inherited declarations; physical specimen identity, fabrication linkage and independent source-unit confirmation remain admission gates. See [the source-specific review](STRUCTURED_SOURCE_REVIEW.md).

The fracture reader decodes all raw load/displacement/time/voltage channels, including negative baseline values and discontinuities. It records blank separators as source-line segments, checks measured-cell units and rejects formulas in selected workbook fields. Author-fitted correction and toughness columns are excluded. Full traces remain curator-only because they contain response information for the geometry-to-Pb2 task. The response remains the stored author-reported Pb2; the reader makes no fracture-event claim. See [the fracture source review](FRACTURE_SOURCE_REVIEW.md).

The biological readers preserve dose-level and dish-level allocation, missing source rows, exact calibration coordinates and exclusions. P100-074 has no biological replicate identifiers. P100-076 contains 39 recording files but only 36 source cell identities; three repeated cells stay within their original dishes. Spike counts are author-derived, and calibration follows sweep order rather than physical file row order. See [the biological source review](BIOLOGICAL_SOURCE_REVIEW.md) for timing, dependence and unit limitations.

The fermentation reader preserves the historical cohort while checking actual timestamps. It identifies 113 nominal six-hour forecasts with different true horizons, interleaved development batches and acquisition windows overlapping the test period. It does not retime, interpolate or drop those rows. See [the fermentation source review](FERMENTATION_SOURCE_REVIEW.md). Whole-batch membership passes, but temporal admission fails and requires a new contract.

The public-goods reader validates 554 participant identities in 277 first-session pairs. The mirrored Type2 sheets verify the same observations and add no samples. Surveys and later sessions never become inputs. Earlier held-out responses legitimately enter subsequent prediction histories under the explicit online one-step contract; this is not free-running or permanently secret-output evaluation. See [the game source review](PUBLIC_GOODS_SOURCE_REVIEW.md).

The risk-choice reader reproduces every historical row while flagging 1,765 repeated trial-order keys and inconsistent ages or sex codes within source IDs. Row-order ties remain visible and are not accepted as chronological evidence. See [the choice source review](RISK_CHOICE_SOURCE_REVIEW.md).

The crowd reader decodes 1,842,039 position measurements in 123 recordings, preserving actual timestamps, source units and per-frame row lineage. It ignores author-supplied velocities/polarization and records seven recordings too short for an eligible window. Condition separation does not establish independent participants or live tracking latency. See [the crowd source review](CROWD_SOURCE_REVIEW.md).

The acoustic-levitation reader checks 31 raw and 31 linked denoised MATLAB files, reconstructing five-millisecond forecasts from raw voltage. The initial 20 samples form the disclosed offset; current and 5/10/15 ms past samples supply delay inputs. Stored 0.5 ms and 1 ms clocks are checked separately. No denoised values or source fitted coefficients enter the task. See [the source review](LEVITATION_SOURCE_REVIEW.md).

The USGS reader reconstructs the complete 2,607-event graph before selecting the 2,545 eligible origin-quality rows. It checks source counts, service revision, preferred-origin identity, missingness and unchanged cluster assignments. Reported uncertainty is a solver product; the draft is recommended as a diagnostic task. See [the ComCat source review](COMCAT_SOURCE_REVIEW.md).

The Rydberg reader preserves the complete source-grid inventory and excludes optical, fitted-summary and RF-calibration responses from predictors. It does not infer independent instrument acquisitions from grid density. The Basytec reader checks all acquisition clocks, merges consecutive commands across step numbers, and records actual prefix and target timing. See [the spectra/battery source review](SPECTRA_BATTERY_SOURCE_REVIEW.md) for processing, chronology, attribution and single-cell limitations.

The fixed selection and calibration definitions follow the existing native preparation specifications, with their original parser hashes recorded for attribution. The implementation is rewritten here and adds source/lineage guards. No legacy runtime, scientific formula, fitting code or evaluator is copied.
